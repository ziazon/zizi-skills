# Ideation Frameworks Reference

Use these frameworks selectively. Pick the lens that fits the idea — don't mechanically run every framework.

- **SCAMPER** (existing products): substitute, combine, adapt, modify, put to other uses, eliminate, reverse — which one changes the idea most?
- **How Might We:** "How might we [outcome] for [specific user] without [key constraint]?" — not solution-embedded, not "make users happy".
- **First principles:** what is actually true, what is only assumed, and what would you build from the truths alone?
- **Jobs to Be Done:** "When I [situation], I want to [motivation], so I can [outcome]" — the competitor is whatever they hire today.
- **Constraint-based:** one day to build, one feature only, free forever, no obvious tech, 10 users vs. a billion.
- **Pre-mortem** (Phase 2): it shipped and flopped 12 months from now — which failure modes are preventable, acceptable, or fatal?
- **Analogous inspiration** (Phase 1): which domain already solved a *structurally* similar problem?
